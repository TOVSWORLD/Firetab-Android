# Getting help

Start with [documentation](docs/README.md), [known limitations](docs/KNOWN-LIMITATIONS.md)
and [troubleshooting](docs/development/TROUBLESHOOTING.md). There is no installable
project firmware today. Do not use historical manifests as an Android 17 installation guide.

Use the question issue form for usage/research questions, the bug form for reproducible
failures, and the test report form for owner-run device results. Include douglas/KFDOWI
or your actual model/codename, source revision and exact command/output where relevant.
A report for another Fire generation is not proof that douglas behaves the same way.

Redact serials, MAC addresses, passwords, tokens, site names, processor addresses,
personal media and private URLs. Do not upload whole unreviewed bugreports or firmware.
Report vulnerabilities privately via SECURITY.md. Community support is best effort;
there is no vendor affiliation, certified Crestron status, or response-time guarantee.
