# Governance and decision making

TOVSWORLD is the repository owner and initial release maintainer. No additional
maintainers or vendor endorsements are implied. Contributors propose changes in issues
and PRs; maintainers decide scope and merge readiness using evidence and user direction.

Small fixes can go directly to a focused PR against development. Architecture, kernel
branch selection, support commitments, invasive compatibility changes and expensive
build infrastructure need an issue explaining alternatives, evidence and acceptance.
Record material decisions in [decision records](docs/project/DECISIONS.md). A proposal
or AI-authored issue does not override an accepted decision.

Contributors retain authorship. Maintainers preserve provenance and only accept material
consistent with LICENSING.md. They may request changes or decline work with a concrete
reason. TOVSWORLD resolves unresolved project disputes; conduct and security reports
follow their private channels. No contribution implies an obligation to fund hardware,
compute, third-party services or long-term maintenance.

Feature PRs target development and pass required checks. Main only accepts same-repo
development release PRs. Neither branch permits direct pushes, force pushes or deletion,
including by admins under the current configured policy. CODEOWNERS requests owner
review; it does not replace required CI or assert independent two-person review.
Release publication remains a deliberate maintainer action, separate from merging.
